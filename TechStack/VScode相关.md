# 便捷设置

1. 按住Ctrl滑动鼠标滚轮来缩放编辑器字体大小：

2. 解锁左边选中文件和当前打开的文件同时打开的连接，这样关掉当前文件，左边文件区就不会自动跳到打开的文件：

- `Ctrl + Shift + V`：纯文本粘贴
- `Alt + 点击`：多光标
- 鼠标中键拖动：列选择 / 块选择，多行一起改特别爽

补几个很常用的，尤其适合 VSCode：

- `Alt + ↑ / ↓`：整行上移/下移
- `Shift + Alt + ↑ / ↓`：复制当前行
- `Ctrl + D`：连续选中下一个相同单词，批量改变量名很好用
- `Ctrl + L`：直接选中整行
- `Ctrl + /`：注释/取消注释
- `Ctrl + P`：快速跳文件
- `Ctrl + Shift + O`：按函数/符号跳转
- `F2`：重命名变量/函数，比手改安全很多
