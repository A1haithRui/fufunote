## 项目一：
> [!info]+ 基于LlaMa-Factory微调Qwen3-VL用于2D目标检测任务(*属于后训练中指令微调的任务适配*)
>项目背景：针对通用视觉大模型在垂直领域空间感知能力弱的不足，引入构建包含130K规模的6D姿态估计数据与通用指令数据的混合流水线。通过指令微调和检测框坐标协议对齐，使Qwen3-VL具有开放领域交互能力同时适配目标检测任务。
>- **视觉定位数据构造**：独立开发BOP格式数据集YCB-V的坐标归一化和Space-Token映射工具，生成对应prompt及bbox语义标签，解决VLM原生空间协议与工业标注间的量程偏移问题。整合LLaVA-instruct指令集并重构统一消息格式转换流程，确保模型在适配检测任务的同时保留文件的开放域图像理解能力。 
>- **参数高效微调**：基于 LlamaFactory 框架采用 LoRA 架构对 Qwen3-VL(8B)指令微调。通过引入 bbox 标签和视觉定位引导， 提升模型的视觉定位能力，实现目标空间位置的精准感知。
>- **成果**：建立端到端Visual Grounding评估体系，在YCB-V测试集上进行验证。微调后的模型在IoU-0.5指标下从零样本的57.5提升至80.5；实验结果表明在工业场景中的重叠、反光情况下有较强鲁棒性并符合标准化空间描述。
#### 前述
这是一个多模态模型的微调项目，为了让开放领域的模型拥有高精度的目标检测能力，我6dof姿态估计任务中的图像数据处理成问答对的形式，并且对对应的bbox格式进行处理，让它按照分辨率缩放到0~1000范围内并截断非法区域处理成qwen3vl模型适配的token格式，同时为了使其保持正常问答能力，又揉了等比例的llava-instruct的通用指令数据集；然后基于Llamafactory进行对Qwen3vl的8b模型进行lora微调。在单张3090上跑了两天左右得到结果模型，然后用YCBV数据集的测试图像进行评估，相比于没有微调的模型，IoU指标从57%提升到了80%。
#### 数据规模和格式
基于 BOP 数据集中的原始图像路径、目标引用和 bbox 标注，构建了面向目标检测任务的基础图文问答样本，并进一步转换为 LlamaFactory 所需的 ShareGPT 风格多模态训练格式，打通了从原始标注到指令微调样本的生成流程。总问答对数目有130k，在实际微调的时候我选取了其中的80k条，因为使用的通用指令数据集LLaVA-instruct的数量是80k的，保证数量比1:1。
#### space-token映射工具
Qwen3VL的手册中的视觉定位任务中，有要求这个检测框的坐标格式。为了统一坐标范围，需要将图像按照分辨率映射到0~1000的统一范围，同时还需要做边界裁剪防止越界导致模型理解错误。这样就可以完成ycb格式数据到qwen的grounding任务的bbox标注。
#### 为什么不用传统检测模型，非要让 VLM 做这个？
我并不认为在纯检测 benchmark 上 VLM 一定优于专用检测器。这个项目更关注的是通用多模态模型能否通过后训练获得结构化空间输出能力。传统检测模型在封闭类别、固定输出协议下很强，但 VLM 的优势在于它可以和自然语言指令结合，做更灵活的开放式视觉交互。所以这个项目更像是在探索通用模型的任务扩展边界，而不是单纯追求比 YOLO 一类模型更高的检测精度。
#### 运行设备
因为用的是LoRA做SFT，所以开销并不大，我的训练配置是8秩，alpha=16，
#### 评估问题，比如开放领域的问答能力怎么验证？目标检测呢？
为了评估混合训练后模型开放域图文理解能力是否发生明显退化，我从通用指令数据中划分出一部分未参与训练的样本作为保留测试集，人为地做定性和基础问答表现检查，观察模型的输出和交互能力是否保持稳定。对目标检测任务本身，我从 YCB-V 中划分未参与训练的若干真实图像作为测试集，将模型输出解析为结构化 bbox 后，与标注框计算IoU。
## 项目二：
> [!info]+ 基于VerL框架的多模态ChartQA视觉推理智能体开发(*用VeRL做DAPO的强化学习*)
>**项目背景：** 面向多模态大模型在复杂长图、高密度图表任务中推理链路长、幻觉严重及空间感知力差的痛点，构建基于 VeRL 的在线强化学习训练流程。项目结合 SFT 和 DAPO 优化模型使其可以自主选择 ReFocus 视觉增强工具来对图表局部区域进行 重聚焦再继续推理，实现观察、增强到决策的闭环，提升复杂图表场景下的回答准确率与过程可解释性。
> - **视觉工具数据管线构建：** 基于 ReFocus 的工具，对 ChartQA 原始样本进行二次加工，将图表中的语义元素与 bbox 空 间位置进行关联和封装，构建支持视觉重聚焦与工具调用监督的结构化训练数据。
> - **算法优化：** 在 VeRL 框架下结合 SFT 和 DAPO 训练多步工具调用流程，第一轮驱动模型生成工具调用指令对原始图像进 行局部重聚焦与增强；第二轮引导模型基于增强后的视觉上下文继续完成答案推理，该流程在高密度图表场景下有助于 缓解关键信息遗漏和错误关注带来的回答偏差。
> - **奖励建模优化：** 设计并实现基于规则的奖励函数。通过正则从模型输出中抽取最终答案，对多候选答案与多真值进行 集合式匹配；针对数值答案与非数值答案分别采用相似度评分和精确匹配，并将输出分数归一化。
#### 前述
考虑到希望将多模态大模型应用到图表任务中，而通用领域的Qwen3VL的准确性和空间分析能力并不够强，所以计划做一个图表任务的强化学习后训练。
原生 VLM 大模型在复杂高密度图表任务上，本身存在三个固有缺陷：一是**空间感知能力弱**，无法精准定位图表局部关键信息；二是**长链路推理能力不足**，推理链路长容易中断；三是**容易产生幻觉，凭空编造图表数值信息**。
针对以上痛点，我没有直接微调模型本体。通过 SFT 监督微调让模型学会识别需要重聚焦的区域，再用 DAPO 强化学习优化工具调用策略，主动调用 ReFocus 视觉增强工具对局部图表放大细看；先增强视觉信息、弥补模型空间感知缺陷，再基于清晰局部信息完成后续推理，**从根源缩短无效推理链路、减少幻觉、提升图表问答准确率**。
>假如问：为什么原生的VLM会出现这些缺陷？
>回答： 原生 VLM 是全局粗粒度视觉编码，面对高密度小区域图表细节，注意力无法聚焦到局部数值、坐标轴等细粒度信息，只能全局模糊理解，因此容易空间定位错误、跳步推理、编造不存在的数据，也就是幻觉。我的重聚焦工具调用，就是把全局模糊视觉，变成局部精细视觉，从输入侧解决根源问题，而不是单纯改输出。
#### 微调
在 SFT 阶段，我使用了 ChartQA 数据集，把图表相关问题和对应答案整理成问答样本，再通过脚本统一转换成 system/user/assistant 的对话格式。训练上采用 LoRA 做参数高效微调，配置是 alpha=16、rank=4，只加在$W_q$和$W_v$上，训练了 4 个 epoch。
这个项目中也用到了多模态RAG(mRAG)，检索阶段用了ColQwen2进行视觉文档检索，重排序阶段用了MonoQwen2-VL对检索结果重排序，生成回答阶段用Qwen3VL基于检索到的图像回答问题。多模态检索是直接检索图像而非文本，且主要将pdf页面转为图像进行索引，先粗排检索top-5，再精排重排到top-3，最后基于检索到的相关页面图像生成答案。
这个阶段的目标主要是让模型先具备基础的图表问答能力和后续工具调用所需的输出格式能力。评估上，当前主要是选取未参与训练的图表样本做定性检查，人工观察模型回答是否合理。
#### RL
在 RL 阶段，首先是引导模型去调用工具，这里用到的图表处理工具是ReFocus，它提供的接口可以对图表的某行某列进行标注、遮挡和高亮，通过该工具完成数据增强，提供有效区域的信息。
数据的prompt里会显示约定refoucs的工具函数，一轮rollout的结果就是模型生成工具调用指令来做视觉增强，随后根据指令直接去编辑图片并且插入到prompt中。二轮rollout让模型基于增强后的视觉上下文生成最终答案。
奖励部分设计了一套基于规则的outcome reward。先从模型输出中抽取最终答案片段，如果提取不到，就直接给 0 分。考虑到真值中可能有多个参考答案，模型输出中也可能有多个候选答案，对于数值答案，按照相似度(即四舍五入后是否一样)打分；对于非数值答案，采用精确匹配。然后让每个候选答案去和所有 ground truth 找最佳匹配分，最后把这些最佳分求和并归一化，得到每条样本的最终标量奖励。打分是调用大模型的api根据query和输出答案进行给分。
reward函数输出每条样本的标量得分，但是他不是每个 token 的 dense reward。后面我把这个 seq-level 的奖励通过 VeRL 的接口对齐到 token-level，一般是挂到最后一个有效 token 的位置上。这样做的好处是，不需要手工设计逐 token 的复杂奖励，也能让 DAPO 利用最终结果分数去优化整条生成轨迹。
#### 评估
目前这个项目的评估还是以保留测试图表上的定性分析为主，主要观察三点：第一，模型生成的工具调用是否合理；第二，增强区域是否确实覆盖了关键信息；第三，最终答案相比不调用工具时是否更稳定、更准确。由于项目周期比较短，系统化的自动评估指标还在后续补充中。
