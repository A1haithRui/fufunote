# 项目一：多模态LoRA微调
> [!info]+ 基于LlaMa-Factory微调Qwen3-VL用于2D目标检测任务(*属于后训练中指令微调的任务适配*)
>项目背景：针对通用视觉大模型在垂直领域空间感知能力弱的不足，引入构建包含130K规模的6D姿态估计数据与通用指令数据的混合流水线。通过指令微调和检测框坐标协议对齐，使Qwen3-VL具有开放领域交互能力同时适配目标检测任务。
>- **视觉定位数据构造**：独立开发BOP格式数据集YCB-V的坐标归一化和Space-Token映射工具，生成对应prompt及bbox语义标签，解决VLM原生空间协议与工业标注间的量程偏移问题。整合LLaVA-instruct指令集并重构统一消息格式转换流程，确保模型在适配检测任务的同时保留文件的开放域图像理解能力。 
>- **参数高效微调**：基于LlamaFactory框架采用LoRA架构对Qwen3-VL(8B)指令微调。通过引入bbox语义标签和视觉定位引导，在标准交叉熵损失基础上加入Token预测环节计算的IoU损失，显著提升模型的视觉定位能力，实现复杂场景下目标空间位置的精准感知和结构化返回。
>- **成果**：建立端到端Visual Grounding评估体系，在YCB-V测试集上进行验证。微调后的模型在IoU-0.5指标下从零样本的57.5提升至80.5；实验结果表明在工业场景中的重叠、反光情况下有较强鲁棒性并符合标准化空间描述。

# 项目二：多模态RL Agent
> [!info]+ 基于VerL框架的多模态ChartQA视觉推理智能体开发(*用VeRL做DAPO的强化学习*)
>**项目背景：**面向多模态大模型在复杂长图、高密度图表任务中推理链路长、幻觉严重及空间感知力差的痛点，构建基于VerL的在线强化学习框架。项目结合SFT和DAPO优化模型使其可以自主选择ReFocus视觉增强工具来动态交互并重构视觉特征，通过双轮推理实现观察与决策的闭环，显著提升了推理过程的可解释性与结果的准确度。
> - **视觉工具数据管线构建：**基于ReFocus逻辑对ChartQA原始图表数据进行二次开发，将图像实体中的语义标签与bbox空间坐标进行映射和封装，构建具备视觉引导特征的结构化数据集。
> - **算法优化：**在VerL框架下结合SFT和DAPO实现双轮推理模式，第一轮驱动模型生成工具调用指令对原始图像进行动态编辑与特征增强；第二轮引导模型基于重构后的视觉上下文进行长链推理，实现从视觉感知到逻辑决策的闭环，显著降低高密度图表场景下的幻觉率。
> - **奖励建模优化：**设计并实现Model-based的多维复合奖励函数，针对视觉Agent的特性，引入空间一致性惩罚(惩罚非信息区域的盲目画框)与逻辑推理奖励(解析后的答案准确度打分)，引导模型建立更加准确的多模态因果关系。
对Qwen3-VL-2B进行在线强化学习训练，使模型在chartQA图表问答任务上更稳定地生成可验证的答案，使用DAPO强化学习让模型先调用工具，执行工具得到编辑后的图像，再把观察结果拼入二次prompt，促使模型在增强视觉输入上回答。

### 1. 数据预处理
### 1.1 数据来源
使用的是[HuggingFaceM4/ChartQA](https://huggingface.co/datasets/HuggingFaceM4/ChartQA/viewer/default/train?views%5B%5D=train&row=0)数据，其中包含图标相关的复杂推理问题，并且是非模板生成的，不会导致答案来自一个固定的词汇表。它涵盖了9.6k个人工编写的问题，以及23.1k个由人工撰写的图标摘要生成的问题。对应的数据[论文](https://aclanthology.org/2022.findings-acl.177.pdf)。
数据中的`question`会提问一些图表中的问题(query)，有的问题涉及推理，给出对应答案(label)，以及对应的是否是人工标注标签(class label)。
然后使用SFT来做微调，这里参考的是另一个项目[先放个空链接]()。通过微调可以让模型在对话中提高该数据集理解的准确率。然后只有对话和图表还不够，现在我们希望给予模型RL Agent(或者说Deep Research)的工具调用方法去进一步提升模型在ChartQA上的表现上限。所以这里就要调用新工具[ReFocus](https://arxiv.org/pdf/2501.05452)来处理，它给ChartQA提供了6种工具用于调用，分别是：

| 工具函数                                 | 作用                      |
| ------------------------------------ | ----------------------- |
| `focus_on_columns_with_hightlight()` | 对指定列加半透明红色高亮            |
| `focus_on_rows_wiht_hightlight()`    | 对指定行加半透明红色高亮            |
| `focus_on_columns_with_mask()`       | 仅保留指定列，其余区域被遮住(强过滤干扰信息) |
| `focus_on_rows_with_mask()`          | 仅保留指定行，其余区域被遮住(强过滤干扰信息) |
| `focus_on_columns_with_draw()`       | 对指定列画红色边框(轻量标注，不改变内容)   |
| `focus_on_rows_with_draw()`          | 对指定行画红色边框(轻量标注，不改变内容)   |
为了方便实现，使用ReFocus的筛选数据集合[ReFocus/ReFocus_Data](https://huggingface.co/datasets/ReFocus/ReFocus_Data/viewer?row=2)，这个可以直接下载，里面的内容就是已经处理过的ChartQA。
```bash
wget -c -O ChartQA.zip "https://huggingface.co/datasets/ReFocus/ReFocus_Data/resolve/main/images/ChartQA.zip?download=true"
```
### 1.2 数据处理
有了ReFocus处理后的数据集，相当于重点区域的标注已经做完了，现在就是要把训练集和验证集格式转换成`parquet`格式，方便verl的tooluse去调用。
这里细节就是把bbox列表变成可索引的字典(value->bbox)
jsonl里的结构是：`x_values: ["18-24", "25-34", ...]`，`x_values_bbox: [{"x1": ..., "y1": ..., ...}, ...]`，把他们zip成：`{"18-24}: {...}, "25-34" {...}, ...}`。然后生成metadata(json字符串)供训练时工具调用，其中包含meta有图的类型(h_bar/v_bar/table等)；图的整体位置(figure_bbox)；x/y值到bbox的映射(给tooluse用)...
直接运行提供的脚本就行，最后在`../datasets`里能找到处理好后的parquet文件。
```bash
python preprocess.py
# ../datasets中会有train_full.parquet和val_full.parquet两个文件
```

cxx11abiTRUE 中 True 或者 False 可通过下面代码查询
```Python
import torch

print(torch._C._GLIBCXX_USE_CXX11_ABI)
```
根据输出选择 True 或者 False，绝大多数条件为 False

## Vllm 无法正常使用
初始安装了 vllm 0.8.5 （手动 pip 安装，并非使用 pip install -e .[vllm]），与现有的 verl 版本不兼容，使得 verl 中需要导入某些库无法正常安装 （vllm.v1.enigne.utils）
此外 vllm 0.8.5 版本是基于 torch 2.6.0，在 vllm 的 github 处寻得 0.11.0 版本能够与当前的 verl 兼容
## Flash-attn 错误
经过查询检查报错信息，指明是 flash-attn 版本与当前其他依赖有冲突，查询后发现并无冲突，但还是重新安装了 flash-attn，后问题解决
## 多个环境依赖有冲突
初次配置环境中，中间并不清楚哪些包是必备的，因此后续多次手动 pip install 某个环境，导致最终多个环境有严重的冲突，且形成死锁无法解决。
最终重新在全新的环境中从头配置环境，按照 **环境创建部分** 不会出现任何问题。
